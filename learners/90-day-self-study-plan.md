# 90-Day Self-Study Plan

**Time:** about 1–2 hours a day. Rest days are built in (every 7th day is review). If you miss a day, don't "catch up" by cramming — just continue.

- **Days 1–30 — Craft:** story, visual language, sound basics.
- **Days 31–60 — Editing + AI tests:** DaVinci Resolve, image and video generation, consistency, first automation.
- **Days 61–90 — Finish a short film:** 2–4 minutes, start to finish, with a pipeline report.

**Budget:** Days 1–40 can be **$0**. From about Day 41, the **Starter stack (~$44/month, ₹4,172)** helps; see [docs/05](../docs/05-ai-filmmaking-tools.md#three-budget-stacks). Prices checked 2026-11-21.

Tick days off in your [progress checklist](progress-checklist.md).

## Phase 1 · Days 1–30: Craft

### Week 1 — Setup and taste
| Day | Task |
|---|---|
| 1 | Read [00 Roadmap](../docs/00-roadmap.md). Install DaVinci Resolve (free). Create the project folder structure from [docs/07](../docs/07-ai-film-workflow-step-by-step.md#project-folder-copy-this). |
| 2 | Create free accounts: one assistant (Claude/ChatGPT/Gemini), one image tool, Google Flow or Kling. Generate your first image and first 5-s clip. Note credits used. |
| 3 | Watch 3 AI shorts from the [Runway AI Film Festival](https://aif.runwayml.com/2024). Write what worked and what felt fake. |
| 4 | Watch 3 traditional shorts you love. Same notes. |
| 5 | Write your "film taste" page: 5 films and *why*. |
| 6 | Start StudioBinder's [free film school](https://www.studiobinder.com/online-film-school): one lesson on story or shot composition. |
| 7 | **Review:** tidy folders, update checklist, rest. |

### Week 2 — Story
| Day | Task |
|---|---|
| 8 | Read [01 Story](../docs/01-story-screenwriting.md). Learn the logline formula. Write 10 loglines. |
| 9 | 10 more loglines. Ask an AI to critique 3 of them (critique only — you rewrite). |
| 10 | Study three-act and five-beat short structure. Map one short film you watched onto it. |
| 11 | Pick your best logline. Write a one-paragraph story outline. |
| 12 | Learn screenplay format (StudioBinder's free screenwriting app). Write page 1. |
| 13 | Write pages 2–3. |
| 14 | **Review:** read the script aloud; cut anything not visible. |

### Week 3 — Visual language
| Day | Task |
|---|---|
| 15 | Read [02 Cinematography](../docs/02-cinematography-visual-language.md). Learn shot sizes; screenshot one example of each from a film. |
| 16 | Lenses and depth of field: generate the same shot at 24, 50 and 85 mm. |
| 17 | Angles: generate high, eye-level, low, Dutch, OTS, POV versions of one moment. |
| 18 | Lighting: three-point, hard vs soft, golden hour, neon — generate 4 versions. |
| 19 | Colour: build a 5-colour palette for your script; generate 3 frames using it. |
| 20 | "One moment, six ways" exercise from docs/02. |
| 21 | **Review:** start your lookbook (8–12 frames). |

### Week 4 — Shot list, sound basics
| Day | Task |
|---|---|
| 22 | Turn your script into a numbered shot list (CSV): shot, size, angle, action, duration. |
| 23 | Read [03 Production & sound](../docs/03-production-directing-sound.md). Learn the four sound layers. |
| 24 | Record 10 foley sounds at home with your phone (door, footsteps, cup, keys...). |
| 25 | Make 3 voices in ElevenLabs free; read your script's first scene with them. |
| 26 | Generate 5 SFX and a 30-s music sketch (Suno free / royalty-free library). |
| 27 | Directing exercise: rewrite 10 action lines as concrete verbs + micro-expressions. |
| 28 | **Review.** |
| 29 | Revise script v2 using everything learned. |
| 30 | **Checkpoint:** script v2 + shot list + lookbook done. Do [Practice Project 1](practice-projects.md#project-1--the-one-shot-mood-piece). |

## Phase 2 · Days 31–60: Editing + AI tests

### Week 5 — DaVinci Resolve basics
| Day | Task |
|---|---|
| 31 | Open the [official Resolve training](https://www.blackmagicdesign.com/products/davinciresolve/training); start the beginner course/book. Learn the pages (Media, Cut, Edit, Color, Fairlight, Deliver). |
| 32 | Import clips, organise bins, make your first timeline. |
| 33 | Cuts, trims, J/L cuts. Edit 10 random clips into a 30-s sequence. |
| 34 | Audio on the timeline: levels, fades, adding music under dialogue. |
| 35 | Titles and export (1080p H.264 MP4 + 9:16). |
| 36 | Read [04 Post](../docs/04-post-production-editing-color.md). Basic colour correction with scopes. |
| 37 | **Review.** |

### Week 6 — Characters and consistency
| Day | Task |
|---|---|
| 38 | Read [06 §2 Consistency](../docs/06-ai-engineer-technical-skills.md#2-character--style-consistency). Write character and style bibles (3–5 lines each). |
| 39 | Generate your lead's character reference sheet ([prompts](../prompts/ai-video-prompt-library.md#2-character-reference-sheets)). |
| 40 | Generate the first 6 keyframes of your shot list using the sheet + bibles. |
| 41 | Generate keyframes 7–12. Grid them; regenerate any that drift. *(Consider upgrading to the Starter stack now.)* |
| 42 | Make an animatic: keyframes on the Resolve timeline with scratch voice. |
| 43 | Fix story problems the animatic revealed. |
| 44 | **Review.** Do [Practice Project 2](practice-projects.md#project-2--the-consistent-character-storyboard). |

### Week 7 — Image-to-video
| Day | Task |
|---|---|
| 45 | Learn camera-move prompts ([library](../prompts/ai-video-prompt-library.md#4-camera-movements)). Animate 1 keyframe 3 ways. |
| 46 | Animate keyframes 1–4. Log credits per take. |
| 47 | Animate 5–8. Try start+end frames for a controlled move. |
| 48 | Learn FFmpeg last-frame extraction ([docs/06 §7](../docs/06-ai-engineer-technical-skills.md#7-ffmpeg-for-stitching-converting-frame-extraction)); chain two shots. |
| 49 | Lip-sync test: one line of dialogue with HeyGen free or your video tool's lip-sync. |
| 50 | Edit the animated shots into your animatic timeline. |
| 51 | **Review.** Do [Practice Project 3](practice-projects.md#project-3--the-30-second-dialogue-scene). |

### Week 8 — Finishing + first automation
| Day | Task |
|---|---|
| 52 | Colour-match clips from two different models in Resolve. |
| 53 | Upscale/interpolate one clip (Resolve, Krea free, or Topaz trial). Compare before/after. |
| 54 | Install Python (or open [Google Colab](https://colab.research.google.com/)). Variables, lists, loops. |
| 55 | Read a CSV in Python and print each prompt. |
| 56 | Run [`batch_generate_videos.py`](../scripts/batch_generate_videos.py) in `--dry-run` with your own CSV. |
| 57 | Set up Git + Git LFS for your project ([docs/06 §9](../docs/06-ai-engineer-technical-skills.md#9-version-control-for-creative-projects-git--git-lfs)). Add `.env` to `.gitignore`. |
| 58 | **Review.** |
| 59 | Optional: put $5–$10 on an API account; run the script for 3 shots with your key in an environment variable. |
| 60 | **Checkpoint:** a 60-s scene, edited, graded, with sound. Do [Practice Project 4](practice-projects.md#project-4--the-automated-music-video). |

## Phase 3 · Days 61–90: Finish a short film

### Week 9 — Pre-production lock
| Day | Task |
|---|---|
| 61 | Read [07 Workflow](../docs/07-ai-film-workflow-step-by-step.md) end to end. Choose your final film (expand your script or a new 2–4 min idea). |
| 62 | Final script lock. |
| 63 | Final shot list (aim 24–40 shots) + credit budget per shot. |
| 64 | Lookbook, character, location sheets final. |
| 65 | Build `prompts.csv` from shot list + bibles. |
| 66 | Generate keyframes for scene 1. |
| 67 | **Review.** |

### Week 10 — Production
| Day | Task |
|---|---|
| 68 | Keyframes for remaining scenes. |
| 69 | Full animatic with scratch voice and temp music. Fix timing. |
| 70 | Record/generate final dialogue and VO. |
| 71 | Animate scene 1 (3–4 takes per shot). |
| 72 | Animate scene 2. |
| 73 | Animate scene 3 / remaining shots. |
| 74 | **Review:** list missing or weak shots. |

### Week 11 — Post-production
| Day | Task |
|---|---|
| 75 | Regenerate weak shots. |
| 76 | Assembly edit (all shots in order). |
| 77 | Rough cut: pacing, J/L cuts, hide artefacts. |
| 78 | Sound design: ambience, SFX, foley. |
| 79 | Music and mix. |
| 80 | Show someone; collect notes. |
| 81 | **Review:** fine cut with notes applied. |

### Week 12–13 — Finish and release
| Day | Task |
|---|---|
| 82 | Interpolate/upscale where needed. |
| 83 | Colour grade: match, look, grain. |
| 84 | Titles, credits with AI disclosure, captions (.srt). |
| 85 | Rights audit ([docs/08](../docs/08-legal-ethics-copyright.md#hands-on-exercise-rights-audit)). |
| 86 | Export master, 9:16 teaser, poster frame. |
| 87 | Write the pipeline report: tools, cost, cost/second, hours, lessons. |
| 88 | Publish online; write a breakdown post. |
| 89 | Shortlist festivals on [FilmFreeway](https://filmfreeway.com/); check AI rules; submit to one. |
| 90 | **Celebrate. Final checkpoint:** [Practice Project 5](practice-projects.md#project-5--the-festival-ready-short) complete. Plan the next 90 days with Stages 6–8 of the [roadmap](../docs/00-roadmap.md). |
